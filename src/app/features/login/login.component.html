Din side hos Percentum

Her logger du sikkert inn på din personlige kundeside. Siden er kryptert og kun tilgjengelig for deg og din rådgiver.

Etter innlogging kan du:

  • Laste opp og se dokumenter (lønnsslipper, skattemelding, regnskap)
  • Følge status på din lånesøknad i sanntid
  • Se og sammenligne tilbud fra banker
  • Signere lånedokumenter og avtaler med BankID
  • Kommunisere direkte med din rådgiver

Vi behandler all opplysninger i henhold til GDPR og Finanstilsynets krav til finanstjenester. Ingenting lagres på e-post.
